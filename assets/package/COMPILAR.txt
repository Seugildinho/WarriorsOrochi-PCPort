WARRIORS OROCHI - PORT PARA PC: CODIGO-FONTE

Esta pasta tem o codigo do port: adaptadores (src), configuracao da compilacao
(config), ferramentas (tools), as correcoes das dependencias (patches) e o
icone (assets). NAO inclui o jogo, a ISO, o codigo recompilado gerado a partir
dele nem as dependencias. Cada pessoa precisa da sua propria ISO do Warriors
Orochi (USA, SLUS-21662).

IMPORTANTE: PASTA CURTA
A compilacao cria arquivos muito fundos e o Windows nao aceita caminhos com mais
de 260 caracteres. Coloque esta pasta num caminho curto, por exemplo C:\WO
(e a ISO ao lado: C:\Warriors Orochi (USA).iso). Na Area de Trabalho ou em
Downloads o caminho fica longo demais e a etapa "toml11" falha.

JEITO FACIL: MAKE
1. Instale o GNU make:      winget install ezwinports.make
   (feche e abra o terminal depois).
2. Coloque a ISO ao lado desta pasta, com o nome exato
   "Warriors Orochi (USA).iso".
3. Nesta pasta:
     make deps       instala o que faltar (Git, Python, Visual Studio Build
                     Tools com C++) e baixa PS2Recomp e PCSX2 nas versoes certas
     make check      confere se esta tudo presente
     make generate   le a ISO e gera o codigo do jogo (demora na primeira vez)
     make install    compila e monta a pasta do jogo "Warriors Orochi"
     make test       roda os testes de regressao
     make reinstall  depois de alterar o codigo: recompila so o que mudou
                     (inclusive arquivos .cpp novos, patches e a configuracao
                     do VU1) e troca os programas na pasta do jogo. Nao refaz
                     a compilacao do zero; saves e configuracoes ficam.
   Depois: abra "Warriors Orochi\WarriorsOrochi-Setup.exe" (ou "make run").
   "make help" lista todos os comandos.

SEM MAKE (passo a passo)
Requisitos: Windows 10/11 64 bits com AVX2, Visual Studio 2022 Build Tools
com C++, Python 3.12 ou superior e Git.
     git clone https://github.com/ran-j/PS2Recomp.git vendor/PS2Recomp
     git -C vendor/PS2Recomp checkout eb8688b2fd191129f103a39543002c005b33409c
     git clone https://github.com/PCSX2/pcsx2.git thirdparty/pcsx2
     git -C thirdparty/pcsx2 checkout fd9d310ccbb6b8b62c976da8886a3c8fd3a10ff3
     git -C thirdparty/pcsx2 apply ../../patches/pcsx2/0001-gs-d3d11-without-dx12-vulkan.patch
     git -C thirdparty/pcsx2 apply ../../patches/pcsx2/0002-sprite-edge-inset.patch
     python tools/inspect_game.py
     python tools/workflow.py tools
     python tools/workflow.py analyze
     python tools/workflow.py generate
     python tools/workflow.py native
     python tools/make_helper.py install
     python tools/run_regressions.py
